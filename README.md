# Math

A collection of mathematics notes, formulas, and computational tools.

## Contents

- **Algebra** — equations, polynomials, matrices
- **Calculus** — limits, derivatives, integrals
- **Linear Algebra** — vectors, eigenvalues, decompositions
- **Probability & Statistics** — distributions, estimation, inference
- **Numerical Methods** — algorithms and implementations

## Getting Started

```bash
git clone https://github.com/<your-username>/Math.git
cd Math
```
